Política de privacidad — Badator! (VERSIÓN FINAL)

Última actualización: 2026-11-23
Responsable: Dev iGoni — Iker Goñi (autónomo, España)
Contacto: dev.mail.igoni@gmail.com

1. Qué hace la aplicación

Badator! permite consultar información de llegadas de autobuses en Donostia / San Sebastián, guardar favoritos, localizar paradas próximas y configurar avisos. La app no es oficial ni está asociada a Dbus o al Ayuntamiento.

2. Datos usados en el dispositivo

  • Ubicación: si el usuario concede el permiso de ubicación aproximada o precisa y solicita buscar paradas cercanas, la aplicación obtiene la ubicación para identificar paradas próximas. Según la implementación revisada en noviembre de 2026, no la persiste. Confirmado: la ubicación solo se usa localmente para ordenar paradas cercanas y nunca se transmite.
  • Favoritos, recientes, preferencias y avisos: almacenados localmente con los mecanismos de persistencia de la app; se utilizan para proporcionar las funcionalidades solicitadas. Confirmado: Room (SQLite local). El usuario borra favoritos/avisos desde la app; desinstalar elimina todo.
  • Notificaciones: si el usuario concede permiso, se utilizan para los avisos configurados. El servicio de seguimiento puede mostrar una notificación persistente mientras está activo.

3. Consultas de red y proveedor externo

Para consultar llegadas, Badator! solicita información a una API externa del servicio de transporte. Estas conexiones pueden revelar al proveedor la dirección IP, metadatos técnicos de conexión y los códigos de las paradas solicitadas. La API de Dbus (http://app.dbus.eus/SSIIMovilWSv2/ws/cons/tiemposParada) responde solo por HTTP. El manifiesto declara `cleartextTrafficPermitted=true` exclusivamente para `app.dbus.eus`. No hay otros endpoints de red. No se puede afirmar «cifrado en tránsito» para toda la app.

Pendiente de auditoría: indicar la identidad legal del operador/proveedor y los enlaces aplicables a su política de privacidad, el tratamiento de IP/metadatos y los plazos de conservación que se conozcan de forma documentada.

4. Analítica, publicidad y terceros

Pendiente: comprobar el AAB final, manifiesto fusionado, dependencias y tráfico. Confirmar si existen SDKs de analítica, publicidad, informes de errores o enlaces remotos adicionales. No afirmar que no hay recopilación ni compartición hasta terminar la auditoría.

5. Conservación y eliminación

Los datos locales se conservan en el dispositivo hasta que el usuario los elimine desde las funciones correspondientes o hasta que desinstale la app, salvo excepciones demostradas por el sistema. Verificar ruta de borrado, backups y efectos de actualizaciones.

Para cualquier solicitud relacionada con los datos personales, el usuario puede contactar con dev.mail.igoni@gmail.com. Si la build no tiene cuentas, describirlo explícitamente una vez verificado.

6. Derechos de los usuarios

Los usuarios pueden solicitar información sobre el tratamiento de sus datos y ejercer los derechos que les correspondan conforme a la normativa aplicable escribiendo a dev.mail.igoni@gmail.com. Añadir identidad del responsable, base jurídica y datos adicionales exigidos tras la revisión de cumplimiento.

7. Menores

Público general (PEGI 3 / Everyone). No dirigida a menores de 13 años. No recopila datos de menores intencionadamente. La aplicación proporciona información sobre transporte público y no debe presentarse como dirigida a niños sin completar el cuestionario de público objetivo y familias.

8. Cambios

Se publicarán las actualizaciones relevantes de esta política en https://ikergoni.github.io/bus-dbus/privacy-policy-es.html.
